# memoire-orm-derive

Procedural macros for [Memoire ORM](https://crates.io/crates/memoire-orm).

You should not depend on this crate directly: use `memoire-orm`, which re-exports
`#[derive(Model)]` and `#[derive(FromRow)]`.
